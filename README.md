سیستم فروش و مدیریت اشتراک اتصال: **ربات تلگرام** + **پنل وب** + **اپ اندروید (JET VPN)** + تأیید خودکار واریز.

## چی هست؟

کاربر از ربات خرید می‌کند، کانفیگ روی پنل نمایندگی ساخته می‌شود و با **اپ JET VPN** یا کلاینت‌های رایج وصل می‌شود. ادمین از ربات یا **Web Admin** مدیریت می‌کند.

```text
کاربر (تلگرام / اپ) → ربات → پنل نمایندگی
                         ↘ MySQL مشترک ↗
                    sms_hook / Web Admin
```

## امکانات اصلی

**کاربر:** خرید و تمدید · تست · کیف پول · کارت‌به‌کارت · زیرمجموعه · پشتیبانی · راهنما و دانلود اپ  

**پرداخت:** مبلغ یکتا · فیش عکس · تأیید ادمین یا **تأیید خودکار پیامک بانک** · چند ادمین  

**ادمین (ربات/وب):** کاربران و سرویس‌ها · فیش‌ها · ساخت دستی سرویس · هدیه حجم/روز · پلن‌ها و کارت · مالی · پشتیبانی · پیام همگانی  

**اپ:** ورود با یوزر/رمز ربات · اتصال از روی سابسکریپشن

## اجزای پروژه

| فایل / پوشه | کار |
|-------------|-----|
| `bot.php` | ربات تلگرام |
| `webadmin/` | پنل وب مدیریت |
| `sms_hook.php` | وب‌هوک تأیید SMS |
| `accounting.php` / `wallet_ledger.php` | مالی و کیف پول |
| `cron.php` / `warn_*.php` | یادآوری و کارهای زمان‌دار |
| `auto_post.php` | پست خودکار کانال |
| `config.php` | تنظیمات سرور (**عمومی نکنید**) |

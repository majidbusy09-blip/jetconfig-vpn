# 🚀 JetConfig — JET VPN & Telegram Sales Bot

سیستم یکپارچه فروش کانفیگ V2Ray/Xray + ربات تلگرام + اپ اندروید اختصاصی **JET VPN**.

- ربات: [@JetConfig1bot](https://t.me/JetConfig1bot)
- کانال: [@jetconfig11](https://t.me/jetconfig11)

---

## 📱 اپلیکیشن اندروید (JET VPN)

- رابط تیره Neon با دکمه اتصال سه‌بعدی
- ورود با نام کاربری / رمز اشتراک
- دریافت خودکار لیست سرورها از API
- **ذخیره آخرین سرور** و بازگردانی بعد از بستن اپ
- **باز شدن سریع** با کش محلی + بروزرسانی سرورها در پس‌زمینه (بدون جابه‌جایی سرور انتخاب‌شده)
- دو حالت تونل:
  - فقط برنامه‌های فیلترشده (بانک، اسنپ و … خارج از تونل)
  - تونل کل گوشی
- نمایش پینگ، ترافیک آپلود/دانلود، حجم و اعتبار
- بروزرسانی دستی کانفیگ‌ها
- لینک مستقیم تمدید از داخل اپ به ربات

> آخرین بیلد را از بخش [Releases](../../releases) دانلود کنید.

## 🤖 ربات تلگرام

### کاربران
- خرید و تمدید آنی (ساخت/تمدید در پنل پاسارگاد)
- تأیید هوشمند واریز با پیامک بانکی (کارت‌به‌کارت)
- کیف پول داخلی، شارژ، انتقال اعتبار
- کد تخفیف
- تست رایگان (در صورت فعال بودن)
- زیرمجموعه‌گیری با پاداش
- سرویس‌های من + QR و لینک ساب
- پشتیبانی هوشمند (AI) + ارجاع به پشتیبانی انسانی
- قفل عضویت کانال

### ادمین
- داشبورد و آمار
- مدیریت کاربران / سرویس‌ها / فیش‌ها
- شارژ دستی کیف پول
- ساخت کانفیگ دستی برای کاربر
- پلن‌ها، کارت‌های بانکی، کد تخفیف
- بکاپ دیتابیس
- کنترل روشن/خاموش بخش‌ها

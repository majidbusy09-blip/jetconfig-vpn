# JetConfig

سیستم فروش و مدیریت اشتراک اتصال — شامل **ربات تلگرام**، **پنل وب مدیریت**، **اپلیکیشن اندروید**، تأیید خودکار واریز و اتصال به پنل نمایندگی.

> این مخزن برای معرفی معماری و قابلیت‌هاست. فایل‌های حساس (`config.php`، توکن‌ها، رمزها) را هرگز در گیت عمومی قرار ندهید.

| بخش | نقش |
|-----|-----|
| **ربات تلگرام** | خرید، تست، کیف پول، پشتیبانی، ادمین |
| **Web Admin** | مدیریت از مرورگر بدون تلگرام |

| **sms_hook** | خواندن پیامک واریز بانک و تأیید خودکار |
| **cron / هشدار** | انقضا، حجم، کارهای دوره‌ای |
| **auto_post** | پست خودکار کانال |

## قابلیت‌های ربات (کاربر)

- خرید اشتراک (پلن مدت‌دار / حجمی)
- دریافت اکانت تست
- کیف پول، شارژ کارت‌به‌کارت، پرداخت با کیف
- تمدید هم‌نوع پلن
- سرویس‌های من + لینک ساب / QR
- معرفی دوستان و پاداش
- پشتیبانی انسانی (تیکت) و در صورت فعال بودن، پاسخ کمکی هوشمند
- راهنمای اتصال و لینک دانلود اپ / کلاینت‌های پیشنهادی (از جمله Happ، v2rayNG، Streisand و …)

### پرداخت

- پیش‌فاکتور با **مبلغ یکتا** (تومان در دیتابیس / ریال روی کارت)
- ارسال عکس فیش → صف تأیید ادمین
- **تأیید خودکار** در صورت تطبیق پیامک بانک با مبلغ فاکتور
- چند ادمین: اعلان برای همه؛ پس از تأیید/رد یکی، پیام بقیه جمع می‌شود

---

## قابلیت‌های ادمین (ربات)

- داشبورد و آمار
- لیست / جستجوی کاربران و سرویس‌ها (فیلتر و مرتب‌سازی)
- تأیید و رد فیش
- ساخت سرویس دستی روی پنل + دیتابیس
- هدیه حجم / روز، حذف فقط از پنل یا حذف کامل
- مدیریت پلن‌ها، کارت بانکی، دکمه‌های منو
- چند ادمین، پیام همگانی، لاگ پشتیبانی
- زیرساخت چندپنلی (آماده توسعه برای پنل‌های دیگر)

## Web Admin

پنل وب **مستقل** از include کردن `bot.php` — فقط دیتابیس و `config` مشترک.

### امکانات

- داشبورد + وضعیت اتصال پنل
- کاربران، جزئیات کاربر، ساخت سرویس دستی، هدیه حجم/روز
- فیش‌های در انتظار و فیش‌های گیرکرده
- سرویس‌ها، پلن‌ها، تنظیمات ربات (دکمه‌ها، کارت، پاداش دعوت)
- پشتیبانی (مشاهده گفتگو و رسانه)
- مالی / خروجی، اکانت تست (خارج از آمار فروش)
- پیام به کاربر و پیام همگانی
- منوی همبرگری گروه‌بندی‌شده (روزانه / کاربران / فروش / سیستم)

### نصب خلاصه

```text
public_html/
  config.php          # مشترک — در گیت نباشد
  bot.php
  sms_hook.php
  ...
  webadmin/
    index.php
    config.local.php  # فقط رمز ورود وب — در گیت نباشد
    ...
```

1. پوشه `webadmin` را کنار ربات آپلود کنید  
2. از `config.local.sample.php` فایل `config.local.php` بسازید و هش رمز را بگذارید  
3. آدرس: `https://your-domain.com/webadmin/`

## اپلیکیشن (JET VPN)

- ورود با نام کاربری و رمز صادرشده از ربات  
- اتصال بر اساس لینک سابسکریپشن پنل  
- گزینه‌های تونل (کل دستگاه / برنامه‌های انتخابی)  
- انتشار در فروشگاه‌های داخلی با توضیحات خنثی (بدون تأکید روی دور زدن محدودیت)

دانلود/ریلیزها معمولاً از مسیر رسمی اعلام‌شده در ربات و کانال در دسترس است.

---

## تأیید خودکار پیامک (`sms_hook.php`)

1. اپ خواننده پیامک روی گوشی ادمین، متن واریز را با `secret` به وب‌هوک می‌فرستد  
2. مبلغ (ریال) با فاکتور pending تطبیق داده می‌شود  
3. در صورت تطبیق یکتا: شارژ کیف یا ساخت/تمدید سرویس در پنل + پیام به کاربر  

**نکته:** مبنای مبلغ در ربات تومان است؛ واریز کارت معمولاً ریال است (×۱۰).

## امنیت (حتماً بخوانید)

- `config.php`، `config.local.php`، لاگ‌ها و بکاپ دیتابیس را **commit نکنید**
- `SMS_HOOK_SECRET` را قوی و خصوصی نگه دارید؛ URL وب‌هوک را عمومی پخش نکنید  
- دسترسی `webadmin` را با رمز قوی و در صورت امکان محدودیت IP/HTTPS اجباری محافظت کنید  
- توکن ربات و رمز پنل نمایندگی را فقط روی سرور نگه دارید  

نمونه `.gitignore`:

```gitignore
config.php
webadmin/config.local.php
*.log
**/backups/
.env
```
